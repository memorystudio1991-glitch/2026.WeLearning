외부 사이트 연결 링크 수정 방법

1
products.js 파일을 메모장이나 VSCode로 엽니다.

프로젝트 폴더 내 products.js 파일에 모든 상품 정보가 모여 있습니다.

2
targetUrl에 연결하고 싶은 링크를 입력합니다. 
{
  id: "w-1",
  title: "리데일리 남여공용 30수 라운드넥 반팔 티셔츠",
  price: "5,890원",
  image: "images/w_yellow_tshirt.jpg",
  targetUrl: "https://이동할_사이트_주소.com" // 👈 여기를 변경!
}
3
저장하면 즉시 클릭 시 변경된 사이트로 연결됩니다!

모든 링크는 새 창(새 탭)에서 안전하게 열립니다.
