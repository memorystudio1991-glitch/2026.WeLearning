# 📅 모여라 (WeMeet) - 친구와 함께하는 주간 약속 조율 웹앱

오늘식당 스타일의 심플하고 직관적인 UI를 바탕으로 제작된 **친구와 1주일 스케줄을 공유하고 만날 수 있는 날짜를 실시간으로 확인하는 웹 애플리케이션**입니다.

---

## 🌟 핵심 기능

1. **원클릭 세그먼트 토글 ([✓ 이용/가능] vs [안 함/바쁨])**:
   - 요일별(월~일) 점심과 저녁 슬롯을 손쉽게 탭하여 내 일정을 1초 만에 업데이트할 수 있습니다.
2. **실시간 만남 최적일 자동 계산**:
   - 나와 친구들(총 4명)의 일정을 교차 분석하여, **모두가 참석 가능한 골든 타임(예: 금요일 저녁 · 토요일 점심)**을 상단 그린 히어로 배너에 실시간 하이라이트합니다.
   - 각 시간대별로 `전원 가능 (4명 모두!)`, `3명 가능` 등의 실시간 참여 인원 정보가 표시됩니다.
3. **친구 시점 전환 기능**:
   - 좌측 상단 드롭다운에서 친구(박민수, 이지은, 최현우)를 선택하여 각 친구의 일정을 열람 및 대리 수정할 수 있습니다.
4. **하단 빠른 일괄 설정**:
   - `주말만 가능으로 일괄 설정`: 평일 야근/바쁨 시 주말만 한 번에 가능으로 변경
   - `모두 가능으로 일괄 설정`: 일주일 전체 슬롯을 한 번에 가능으로 변경
5. **친구별 전체 비교 매트릭스 모달**:
   - `친구별 전체 일정표 보기` 버튼을 누르면 전원의 일정을 표 형태로 한눈에 비교할 수 있습니다.
6. **로컬 스토리지 자동 저장**:
   - 브라우저를 새로고침하거나 껐다 켜도 데이터가 로컬 스토리지에 안전하게 보존됩니다.

## 📁 파일 구조

```
스케쥴 관리 웹/
├── index.html        # 메인 웹 페이지 마크업
├── style.css         # 세이지/딥그린 테마 디자인 시스템
├── app.js            # 실시간 일정 매칭 알고리즘 및 인터랙션 로직
└── README.md         # 서비스 설명 문서
```

---

## 🖥️ 실행 방법

- 웹 브라우저에서 `index.html` 파일을 더블 클릭하여 바로 실행할 수 있습니다.
- 로컬 웹 서버 실행 시: `http://127.0.0.1:8080/스케쥴%20관리%20웹/index.html`
