# 📅 모여라 (WeMeet) - 친구와 함께하는 주간 약속 & 조깅 조율 웹앱

오늘식당 스타일의 심플하고 직관적인 그린 UI를 바탕으로 제작된 **친구와 1주일 스케줄(점심, 저녁, 조깅) 및 비고 메모를 공유하고 만날 수 있는 날짜를 실시간으로 확인하는 웹 애플리케이션**입니다.

---

## 🌟 핵심 기능

1. **기본 2명 참여 및 자유로운 친구 추가/삭제 (확장형 구조)**:
   - 처음에는 **김건영(나)**과 **박민수(친구)** 2명으로 시작합니다.
   - 상단 또는 사이드바의 `+ 친구 추가` 버튼을 눌러 언제든 새로운 친구를 추가할 수 있고, 필요 시 삭제도 가능합니다.
   - 좌측 상단 드롭다운을 통해 참여자별 시점을 전환하여 각자의 일정을 편집할 수 있습니다.

2. **3가지 활동 항목 (점심 · 저녁 · 조깅)**:
   - 각 요일마다 **점심(🥪)**, **저녁(🌙)**, **조깅(🏃)** 3개 슬롯이 배치되어 있습니다.
   - 원클릭 세그먼트 버튼(`[✓ 가능]` vs `[✕ 안됨]`)으로 각 활동의 참석 여부를 손쉽게 토글합니다.

3. **일자별 비고란 (메모 입력 기능)**:
   - 각 요일 행 아래에 **비고 (메모)** 입력란이 제공됩니다.
   - 예: *"강남역 저녁 7시 가능"*, *"오전 7시 한강 가벼운 조깅"* 등의 텍스트를 입력하면 실시간으로 자동 저장됩니다.

4. **실시간 만남 & 운동 최적일 자동 계산**:
   - 참여자 전원의 일정을 실시간으로 교차 분석하여, **모두가 가능한 최적의 시간대(예: 금요일 저녁 · 토요일 조깅)**를 상단 히어로 배너에 즉시 추천합니다.

5. **친구별 전체 비교 매트릭스 모달**:
   - `전체 일정 비교표 보기` 버튼을 누르면 전원의 점심, 저녁, 조깅 가능 여부와 비고 메모를 한눈에 표 형태로 비교할 수 있습니다.

6. **로컬 스토리지 자동 저장**:
   - 브라우저를 새로고침하거나 창을 닫아도 내 일정, 친구 목록, 비고 메모가 로컬에 안전하게 유지됩니다.

7. **📱 아이폰 & 갤럭시 모바일 전용 반응형 웹 (New!)**:
   - 스마트폰이나 태블릿 등 좁은 화면으로 접속 시 자동으로 모바일 전용 앱 레이아웃으로 전환됩니다.
   - **상단 모바일 앱바**: 햄버거 메뉴 및 초대 링크 공유
   - **오프캔버스 드로어 사이드바**: 화면 좌측에서 부드럽게 열리고 닫히는 모바일 전용 메뉴
   - **하단 고정 탭바(Bottom Nav)**: 한 손 엄지손가락으로 [홈], [이번 주], [다음 주], [전체 비교] 간편 이동
   - **일별 카드형 레이아웃**: 가로 스크롤 없이 세로 스크롤만으로 나와 친구의 일정을 위아래로 한눈에 비교하고 탭하여 조율 가능

## 📁 파일 구조

```
스케쥴 관리 웹/
├── index.html        # 메인 웹 페이지 마크업 (모바일 상단 앱바, 하단 탭바, 모달)
├── style.css         # 세이지/딥그린 테마 디자인 시스템 + 모바일 미디어 쿼리
├── app.js            # 상태 관리, 모바일 드로어/하단탭 제어, 매칭 알고리즘
├── README.md         # 서비스 설명 및 사용 가이드
└── *.bak             # 안전한 원본 보존을 위한 사본 백업 파일
```

## 🖥️ 실행 및 모바일 화면 확인 방법

1. **PC 일반 실행**:
   - 웹 브라우저에서 `index.html` 파일을 더블 클릭하여 바로 실행할 수 있습니다.
2. **📱 모바일 화면(아이폰/갤럭시) 테스트 방법**:
   - 브라우저(크롬 또는 엣지)에서 `F12` 키를 누릅니다.
   - 개발자 도구 좌측 상단의 **디바이스 툴바 아이콘(`Ctrl + Shift + M`)**을 클릭합니다.
   - 상단 기기 목록에서 **`iPhone 14 Pro`** 또는 **`Samsung Galaxy S20`** 등을 선택하시면 실제 스마트폰 화면으로 바로 확인하실 수 있습니다.
