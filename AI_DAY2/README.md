# 🦴 AI_DAY2 - 인체 스켈레톤(Pose Estimation) 인식 프로젝트

PC 웹캠 및 스마트폰 카메라를 통해 실시간으로 사람의 관절(33개 랜드마크)을 감지하고 뼈대(Skeleton)를 시각화하는 인공지능 비전 프로젝트입니다.

---

## 🌟 2가지 실행 모드 제공

### 📱 1. 스마트폰 카메라 연동 모드 (QR 코드 스캔) ⭐ 추천
스마트폰에 앱을 깔 필요 없이, PC 화면의 QR 코드를 스캔하여 모바일 브라우저(Safari, Chrome)에서 스마트폰 카메라로 실시간 스켈레톤을 체험할 수 있습니다.

#### 실행 방법
1. [`run_mobile.bat`](file:///c:/AI_TEST/AI_DAY2/run_mobile.bat) 파일을 더블 클릭합니다.
2. PC 화면에 나타난 **QR 코드**를 스마트폰 기본 카메라로 비추고 링크를 터치합니다.
3. 최초 접속 시 브라우저의 1회성 보안 확인 창에서:
   * **아이폰 (Safari)**: `[세부사항 보기]` ➔ `[이 웹사이트 방문]` 클릭
   * **갤럭시 (Chrome)**: `[고급]` ➔ `[해당 사이트로 이동(안전하지 않음)]` 클릭
4. **'카메라 사용 권한'**에서 `[허용]`을 누르면 스마트폰 화면에 실시간 네온 뼈대가 나타납니다!

#### 모바일 화면 주요 기능
* 🔄 **전면/후면 카메라 전환**: 셀카 모드 ↔ 상대방/전신 촬영 모드 자유 전환
* 🎨 **모드 변경**: 카메라 영상 오버레이 ↔ 네온 다크 사이버틱 모드
* 📸 **순간 캡처**: 뼈대가 합성된 화면을 폰 앨범에 즉시 사진 파일로 다운로드
* ⚡ **실시간 초당 프레임(FPS) 및 인체 감지 상태 표시**

---

### 💻 2. PC 로컬 웹캠 모드
노트북이나 PC에 연결된 웹캠으로 직접 스켈레톤을 인식하는 프로그램입니다.

#### 실행 방법
1. [`run.bat`](file:///c:/AI_TEST/AI_DAY2/run.bat) 파일을 더블 클릭합니다.
2. 웹캠 화면 창이 나타나면 사람을 비추고 다음 단축키로 조작합니다:
   * **`m`** : 모드 전환 (영상 오버레이 ↔ 네온 다크 모드)
   * **`s`** : 스크린샷 캡처 (`screenshots/` 폴더에 저장)
   * **`f`** : 상단 정보 HUD 켜기/끄기
   * **`q`** 또는 **`ESC`** : 프로그램 종료
