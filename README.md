## 1. 🛒 HOT! TREND - 카테고리별 추천 상품 큐레이션 웹사이트 (`index.html`)

쿠팡 스타일의 카테고리별 상품 추천 및 외부 사이트 연결 큐레이션 웹사이트입니다.

### 🌟 주요 기능
- **카테고리별 상품 큐레이션**: 여성패션(핑크), 남성패션(블루) 등 추천 상품 배치 (3열 x 2행 그리드, 로켓배송 뱃지)
- **아울렛 브랜드 세일 전용 특가 기획전 창**: 배너 클릭 시 화면 내에서 실시간 마감 타이머가 포함된 특가 기획전 창 오픈 및 쿠폰 다운로드
- **외부 링크 원클릭 연결**: 상품/배너/키워드 클릭 시 지정된 외부 사이트로 새 창 이동
- **손쉬운 수정**: `products.js`에서 링크, 상품명, 가격 간편 수정

## 2. 📅 모여라 (WeMeet) - 친구와 함께하는 주간 약속 조율 웹앱 (`schedule.html`)

오늘식당 스타일의 심플하고 감각적인 UI를 바탕으로, 친구들과 1주일 스케줄을 공유하고 **만날 수 있는 최적의 날짜를 직관적으로 찾는 서비스**입니다.

### 🌟 주요 기능
- **원클릭 세그먼트 토글**: 요일별(월~일) `점심 / 저녁`에 대해 `[ ✓ 이용/가능 ]`과 `[ 안 함/바쁨 ]`을 탭하여 실시간 변경
- **실시간 만남 최적일 자동 계산**:
  - 나와 친구들의 일정을 교차 분석하여, **모두가 만날 수 있는 황금 시간대(예: 금요일 저녁 · 토요일 점심)**를 상단 그린 히어로 배너에 실시간 하이라이트
  - 각 시간대별로 `전원 가능 (4명 모두!)`, `3명 가능` 등 참여 인원 수와 명단 표시
- **친구 시점 전환 기능**: 드롭다운에서 친구(박민수, 이지은, 최현우)를 선택하여 각 친구의 일정 확인 및 대리 입력 가능
- **하단 빠른 일괄 설정**:
  - `주말만 가능으로 일괄 설정` (평일 바쁨 자동 처리)
  - `모두 가능으로 일괄 설정`
- **친구별 전체 비교 매트릭스 모달**: 요일별/시간대별 전원 일정 일치 여부를 한눈에 표로 비교
- **로컬 스토리지 자동 저장**: 브라우저를 새로고침해도 입력해 둔 일정이 사라지지 않고 안전 보존
- **초대 링크 복사**: 상단 및 프로필 영역 버튼을 통해 친구들에게 링크 공유
