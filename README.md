# 🛒 HOT! TREND - 카테고리별 추천 상품 큐레이션 웹사이트

쿠팡 스타일의 카테고리별 상품 추천 및 외부 사이트 연결 큐레이션 웹사이트입니다.

---

## 🌟 주요 기능

1. **카테고리별 상품 큐레이션**:
   - 여성패션(핑크), 남성패션(블루) 등 카테고리별 추천 상품 배치
   - HOT 키워드 해시태그 목록
   - 3열 x 2행 (총 6개) 상품 그리드 및 로켓배송/판매자로켓 시그니처 배지
2. **아울렛 브랜드 세일 전용 특가 기획전 창**:
   - 대형 모델 배너 클릭 시 화면 내에서 실시간 마감 타이머가 포함된 특가 기획전 창 오픈
   - 선착순 할인 쿠폰 다운로드 기능
   - 단독 특가 상품 리스트 및 외부 링크 연결
3. **외부 링크 원클릭 연결**:
   - 상품, 배너, 키워드 클릭 시 새 창(`target="_blank"`)으로 외부 사이트 이동
4. **손쉬운 상품/링크 관리**:
   - `products.js` 파일에서 링크, 상품명, 가격, 이미지를 직관적으로 수정 가능
5. **반응형 웹 디자인**:
   - 데스크톱, 태블릿, 모바일 뷰포트에 맞춤 최적화

---

## 📁 파일 구조

```
├── index.html        # 메인 웹 페이지 마크업
├── style.css         # 디자인 시스템 및 반응형 CSS
├── products.js       # 카테고리, 상품 목록, 외부 연결 URL 데이터
├── app.js            # 동적 렌더링, 타이머, 모달 창 로직
└── images/           # 고화질 상품 및 배너 이미지
```

---

## 🚀 링크 수정 방법

`products.js` 파일의 `targetUrl`에 원하는 링크를 입력하시면 즉시 반영됩니다.

```javascript
{
  id: "w-1",
  title: "리데일리 남여공용 30수 라운드넥 반팔 티셔츠",
  price: "5,890원",
  image: "images/w_yellow_tshirt.jpg",
  targetUrl: "https://연결할_사이트_주소.com" // 👈 여기를 수정!
}
```
